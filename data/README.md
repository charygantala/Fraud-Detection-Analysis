# Dataset

The original fraud-detection datasets are intentionally excluded from this repository because the raw and processed CSV files are very large.

Expected project data may include transaction and identity data used by the notebook.

To reproduce the analysis:

1. Obtain the authorized/source dataset.
2. Place it in the local data directory using the filenames expected by `analysis.ipynb`.
3. Run the notebook from top to bottom.

Do not commit large raw datasets, private data, credentials, or other sensitive files to GitHub.
